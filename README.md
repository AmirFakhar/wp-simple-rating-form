# Simple Rating Form

افزونهٔ فارسی وردپرس برای امتیازدهی ۱ تا ۱۰ و دریافت نظر اختیاری برای امتیازهای کمتر از ۵.

## نصب
1. فایل `simple-rating-form.zip` را از بخش «افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه» نصب و فعال کنید.
2. یک بلوک «کد کوتاه» در برگهٔ دلخواه قرار دهید و `[simple_rating_form]` را در آن بنویسید.
3. گزارش‌ها در «ابزارها ← بازخوردها» در دسترس مدیر سایت قرار دارند.

اگر کد را از GitHub دانلود می‌کنید، پوشهٔ حاوی `simple-rating-form.php` و `assets` را در `wp-content/plugins` قرار دهید و سپس فعال کنید.

## قابلیت‌ها
- فرم واکنش‌گرا و راست‌به‌چپ؛ قابل استفاده با صفحه‌کلید
- ارسال بدون بارگذاری مجدد و پیام موفقیت یا خطا
- نمایش نظر فقط برای امتیازهای ۱ تا ۴، حداکثر ۲۰۰۰ نویسه
- اعتبارسنجی سمت سرور، nonce تازه برای سازگاری با کش صفحات، پاک‌سازی ورودی و escape خروجی
- گزارش تعداد، میانگین و فهرست صفحه‌بندی‌شده، فقط برای مدیران
- فیلد تلهٔ ربات و محدودسازی ابتدایی یک ارسال در دقیقه به‌ازای IP

## داده‌ها و محدودیت‌ها
وردپرس ۶٫۲ به بالا و PHP ۷٫۴ به بالا لازم است. جدول مستقل `{prefix}afr_rating_submissions` شامل امتیاز، نظر و زمان محلی سایت است. نام، ایمیل و IP خام ذخیره نمی‌شوند؛ هش نمک‌دار IP برای محدودسازی یک‌دقیقه‌ای در transient ذخیره می‌شود. پشت پراکسی، IP مشترک می‌تواند محدودسازی مشترک ایجاد کند. این محدودسازی ساده تضمین جلوگیری از رأی تکراری یا حملهٔ هم‌زمان نیست. برای سایت پرترافیک از محدودسازی در لایهٔ سرور استفاده کنید.

حذف یا غیرفعال‌کردن افزونه، بازخوردها را حذف نمی‌کند. انتقال اطلاعات جدول افزونهٔ قدیمی خودکار نیست. هیچ داده‌ای به سرویس خارجی ارسال نمی‌شود. برای چندسایتی، فعال‌سازی جداگانه در هر سایت انجام دهید؛ فعال‌سازی شبکه پشتیبانی نشده است.

## بررسی دستی پیش از استفادهٔ عمومی
روی محیط آزمایشی وردپرس: افزونه را فعال کنید، فرم را در برگه قرار دهید، امتیاز ۴ همراه نظر و سپس پس از یک دقیقه امتیاز ۵ ارسال کنید. مخفی‌شدن کادر نظر برای ۵، ثبت رکوردها و میانگین در گزارش را بررسی کنید. مهمان و مدیر، دو فرم در یک صفحه، موبایل و کش صفحه را نیز امتحان کنید. ورودی نامعتبر، nonce نامعتبر و ارسال مجدد زیر یک دقیقه باید رد شوند.

این پیاده‌سازی تازه براساس نیازمندی‌های پروژهٔ `AmirFakhar/00-wp-rating-plugin` نوشته شده است؛ کد آن مخزن کپی نشده است.
